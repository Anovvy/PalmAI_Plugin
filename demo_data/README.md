# **Data Demo PalmAI**
## This guide is designed to provide sample geospatial data (orthophotos) so that you can immediately test the functionality of the PalmAI plugin without having to prepare your own data.

## **Download Trial Data (coming soon)**
As the raster files (GeoTIFF) are quite large, we do not store them directly in this GitHub repository. Please download the sample files via the link below:
| File Name | Description | Size | Download Link |
|---|---|---:|---|
| `sample_ortho_palm.tif` | High-resolution drone imagery (GSD ~5 cm) of a block of oil palm plantations. Suitable for **Tree Counting** and **Centre Tree** trials. | ~150 MB | [ Download](https://drive.google.com/...) |
| `sample_road_network.tif` | Citra orthophoto area perkebunan luas untuk pengujian *Road Detection* (DeepLabV3+). | ~300 MB | [ Download](https://drive.google.com/...) |
